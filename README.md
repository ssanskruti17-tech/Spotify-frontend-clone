## 🎵 About the Project

This project is a frontend recreation inspired by Spotify's web player. It was created to practice HTML and CSS by building a familiar music-streaming interface.

The design includes a sidebar for navigation and library options, playlist and podcast prompts, a sticky top navigation bar, and a bottom music-player section.

The focus of this project is **frontend layout, styling, and visual design** rather than music playback functionality.

## ✨ Features

- 🏠 Home and Search navigation layout
- 📚 Your Library section
- 🎶 Playlist creation prompt
- 🎙️ Podcast discovery prompt
- ⬅️ Back and forward navigation icons
- 💎 Explore Premium and Install App buttons
- 🎨 Dark theme inspired by Spotify's interface
- 📌 Sticky navigation bar
- 🎧 Fixed bottom music-player section
- 📱 CSS media query for selected navigation elements

> **Note:** This is a frontend-only project. Functional search, playlist creation, podcast browsing, and music playback are not implemented.
